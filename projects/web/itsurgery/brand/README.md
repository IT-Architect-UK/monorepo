# IT Surgery brand assets (off-site)

Images used on other platforms, generated from the site's logo and `site.json`
by `tools/build-brand-assets.js`. Re-run it after a logo or tagline change and
re-upload wherever each is used.

| File | Size | Used for |
|------|------|----------|
| `social-square-1200.png` | 1200x1200 | Google Ads square image, Instagram, any square slot |
| `facebook-profile-720.png` | 720x720 | Facebook Page profile picture (the cross; Facebook crops to a circle) |
| `facebook-cover-1640x924.png` | 1640x924 | Facebook Page cover. Text is kept central so the mobile crop (which trims the sides) keeps it |

The on-site share card, `src/assets/og-image.png` (1200x630), is generated by
`tools/build-og-image.js` and is also the landscape image in Google Ads.

Where they are in use (September 2026): Google Ads campaign "Curing IT
Headaches" (landscape + square + cross logo); Facebook Page facebook.com/itsurgery
(profile + cover).
